# المرحلة الثانية — تصوّر صفحة الدرس وخطة التغييرات التقنية (للاعتماد قبل التنفيذ)

> **لا كود منفَّذ.** هذا المستند تصوّر + خطة، بانتظار موافقتك المنفصلة.

---

## ١) المشكلة التي تعالجها المرحلة الثانية (قياسًا على الكود الحالي)

| # | ما هو موجود الآن | ما ينتج عنه |
|---|---|---|
| ١ | الخطوة هي وحدة التنقّل الوحيدة، وقد تحتوي: نصًّا + معجمًا + شرحين + قاعدة + ٥–٨ أنشطة (مثال: `u2l1-s5` فيه ١٨ بلوكًا) | تمرير طويل بلا نقاط توقّف، والطالب لا يعرف موقعه داخل الخطوة |
| ٢ | `LessonStep.type` (‏`reading_passage`/`rule_formulation`/`interactive_practice`/`summary`…) موجود في الأنواع و**غير مستخدم إطلاقًا** في العرض | لا تجميع، لا أيقونة، لا لون دلالي |
| ٣ | زرّا التنقّل لا يذكران اسم الخطوة القادمة/السابقة | الطالب لا يعرف إلى أين يذهب |
| ٤ | الإعراب مدفون: ٨ سجلات داخل قسم القواعد في الخطوة ٦، و١٩ جملة في صفحة Overlay تُغطّي الدرس وتُخفيه بـ`hidden` (لا route، فلا يعمل زر الرجوع) | الإعراب بلا مكانة تعليمية، والتنقّل إليه غير طبيعي |
| ٥ | ٦ مصيّرات دروس (٤١٣٩ سطرًا) تعيد بناء نفس أنواع البلوكات بـJSX منسوخ؛ `.block-source-head` + `source-label-original` ٣٥ مرة | أي تحسين بصري يجب تكراره ٦ مرات، ويختلف بين درس وآخر |
| ٦ | التوزيع بـ`step.id.startsWith('l2-')` داخل `StepRenderer` المشترك | إضافة درس = تعديل ملف مشترك (خطر انحدار) |

## ٢) تصوّر بصري لصفحة درس نموذجية (الدرس ١ — الخطوة ٦: قواعد اللغة)

```
┌──────────────────────────────────────────────────────────────────────────────────────────────┐
│  الرئيسية ← الوحدة الأولى: أحلامي وطموحاتي ← الدرس ١                                          │
├──────────────────────────────────────────────────────────────────────────────────────────────┤
│  السَّمَكَةُ الذَّهَبِيَّةُ                                    [الخطوة ٦ من ١٠ ●●●●●●○○○○]        │
│  أحلامي الكبيرة... كيف أُحقّقها؟ · الصف الخامس الأساسي · ٩٠ دقيقة        [→ العودة إلى الوحدة]   │
└──────────────────────────────────────────────────────────────────────────────────────────────┘
┌──── الشريط الجانبي (٢٦٤px، لاصق) ────┐ ┌──── محتوى الخطوة ────────────────────────────────────┐
│ موضعك في الدرس                       │ │  قَواعِدُ اللُّغَةِ: الجُمْلَةُ          ص ٨ · موثّق ✓  │
│ الخطوة ٦ من ١٠                       │ │  ──────────────────────────────────────────────────── │
│                                      │ │  ┌ من الكتاب ─────────────────────────────────┐      │
│ خطوات الدرس                          │ │  │ ⟡ النص الأصلي · الجملة                     │      │
│ ▸ ٠١ أستكشفُ الصُّورتَيْنِ             │ │  │ «الجملةُ...» (Amiri · 68ch · سطر ٢٫١)       │      │
│ ▸ ٠٢ أَسْتَمِعُ وَأَتَحَدَّثُ           │ │  └────────────────────────────────────────────┘      │
│ ▸ ٠٣ أَقْرَأُ النَّصَّ                 │ │  ┌ القاعدة اللغوية ───────────────────────────┐      │
│ ▸ ٠٤ الفَهْمُ القِرائِيُّ             │ │  │ الجملة الاسمية / الفعلية + مثالان            │      │
│ ▸ ٠٥ أُتَواصَلُ شَفَوِيّاً             │ │  └────────────────────────────────────────────┘      │
│ ◉ ٠٦ قَواعِدُ اللُّغَةِ   «الآن»        │ │  ┌ شرح المنصّة ──────────────────────────────┐      │
│ ▸ ٠٧ إملاء: الهَمْزَةُ الأَوَّلِيَّةُ    │ │  │ كيف أميّز… (خطّ جانبي متقطّع = إضافة منصّة)  │      │
│ ▸ ٠٨ الخطُّ: الحَرَكاتُ               │ │  └────────────────────────────────────────────┘      │
│ ▸ ٠٩ أُعَبِّرُ كِتابِيّاً              │ │  ┌ مثال ──────────────────────────────────────┐      │
│ ▸ ١٠ أَلْعَبُ وَأَتَعَلَّمُ             │ │  ┌ نشاط ٢ · اختيار من متعدد ──────────────────┐      │
│ ────────────────────                 │ │  │ تعليمات · خيارات · [تحقّق من إجاباتي]         │      │
│ أقسام مستقلّة                        │ │  │ نتيجة + تعليل + [أظهر الجواب]                │      │
│ ◆ الإعراب  (١٩ جملة · ٨ أمثلة)       │ │  └────────────────────────────────────────────┘      │
└──────────────────────────────────────┘ ├──────────────────────────────────────────────────────┤
                                         │ [→ السابقة: أُتَواصَلُ شَفَوِيّاً]  [التالية: إملاء: الهَمْزَةُ ←]│
                                         └──────────────────────────────────────────────────────┘
```

**قواعد ثابتة في هذا التصميم:**

1. **هوية البصر لكل نوع بلوك** (شكل + أيقونة + تسمية، لا لون وحده):

   | البلوك | الخلفية/الحدّ | الخطّ | التسمية الظاهرة |
   |---|---|---|---|
   | نصّ الكتاب / الأمثلة الشعرية | `--source-surface` + حدّ ٤px دافئ | Amiri · `--text-book` | «من الكتاب · ص ٨» |
   | القاعدة | `--teal-50` + حدّ علوي ٣px | واجهة | «القاعدة» |
   | شرح المنصّة | `--brand-50` + حدّ جانبي متقطّع | واجهة | «شرح المنصّة» |
   | مثال/شاهد | أبيض + حدّ جانبي + علامة «”» | Amiri | «مثال» |
   | نشاط | بطاقة بيضاء + رأس مرقّم | واجهة | «نشاط ٣» + النوع |
   | حدّ مصدر معلن | `--warn-50` + إطار متقطّع | واجهة | «حدّ مصدر معلن» |

2. **رقم الخطوة في الرأس** (كان في الشريط فقط) + اسم الخطوة التالية/السابقة في الزرّين.
3. **«أقسام مستقلّة»** مجموعة منفصلة أسفل الخطوات في الشريط: لا تأخذ رقم خطوة، ولا تدخل في عدّاد «٦ من ١٠»، ولا تُحفظ كموضع تعلّم (الحفظ يبقى `stepId` فقط — لا تغيير في العقد).
4. على العرض < ٩٢٠px يتحوّل الشريط إلى `<select>` القائم (`lesson-mobile-navigation`) بعد إعادة تنسيقه.

## ٣) تصوّر قسم «الإعراب» المستقلّ

```
┌── الإعراب ───────────────────────────────────────────────────────────────┐
│ الإعراب التطبيقي — الدرس الأول        [١٩ جملة] [سجلّ الإشكالات ١]        │
│ الجمل: من الكتاب   ·   الإعراب: شرح المنصّة   ← تسميتان ظاهرتان دائمًا     │
├──────────────────────────────────────────────────────────────────────────┤
│ ① «على الشّاطئِ يعيشُ صيّادٌ فقيرٌ.»                       ص ٥ · موثّق ✓     │
│ الهدف التعليمي: جار ومجرور متقدم، وفعل مضارع، وفاعل ونعت مرفوعان.          │
│ ┌───────────┬────────────┬───────────────────┬──────────────────────────┐ │
│ │ الكلمة     │ الوظيفة     │ الإعراب            │ العلامة وسببها            │ │
│ ├───────────┼────────────┼───────────────────┼──────────────────────────┤ │
│ │ على        │ حرف جر     │ مبني على السكون    │ لا علامة: حرف مبني        │ │
│ │ الشّاطئِ    │ اسم مجرور  │ مجرور بعلى         │ الكسرة الظاهرة            │ │
│ │ يعيشُ      │ فعل        │ مضارع مرفوع        │ الضمة الظاهرة             │ │
│ │ صيّادٌ      │ فاعل       │ مرفوع              │ الضمة (تنوين ضم)          │ │
│ │ فقيرٌ       │ نعت        │ نعت لصيّاد مرفوع   │ الضمة؛ النعت يتبع منعوته  │ │
│ └───────────┴────────────┴───────────────────┴──────────────────────────┘ │
│ [الجملة السابقة]  [الجملة التالية]           (بلا فقدان موضع الطالب)       │
└──────────────────────────────────────────────────────────────────────────┘
```

- الكلمة المستهدفة تُميَّز داخل الجملة بـ**سُمك + إطار + خلفية خفيفة** (لا لون وحده).
- نموذج بيانات واحد `LessonParsingEntry` بحقول اختيارية؛ **أي حقل غير موجود في المصدر لا يُرسم** (لا يُخترع «سبب العلامة»).
- سجلّ الإشكالات يبقى ظاهرًا كملاحظة تدقيقية، لا كإعراب.

### خريطة الإعراب الموثّق في الدروس الستة (نتيجة التدقيق)

| الدرس | ما هو موجود فعلًا في المصدر | القرار |
|---|---|---|
| ١ — السَّمَكَةُ الذَّهَبِيَّةُ | ١٩ جملة كلمة‑كلمة (`LESSON1_IRAB_PAGE`) + ٨ سجلات `LESSON1_IRAB` + ١ جملة مستبعدة | **قسم كامل** بالحقول الخمسة (كلمة/نوع/موقع/علامة/سبب) |
| ٣ — لُغَتي | «المثال المعرب»: ٤ كلمات معربة نصًّا في `source_sentences` (ص ٢٩) | قسم **بعرض مبسّط**: كلمة + إعرابها كما في الكتاب فقط |
| و٢ / ١ — مُخْتَرِعٌ مِنْ بِلَادِي | `worked_example` بعنوان «المثالان المعربان» (ص ٤٥، ٤ كلمات)، و`explanation` «كيف أكتب إعرابًا كاملًا؟» | قسم **بعرض مبسّط** من المصدر نفسه |
| و٢ / ٣ — بِالْعِلْمِ تَرْقَى | «مثالان معربان (من الكتاب)» داخل `source_info.lines` (ص ٦٥) | قسم **بعرض مبسّط** |
| ٢ — بِالرَّأْيِ وَالرَّأْيِ الآخَرِ | لا نصّ إعراب مهيكل (إشارات عابرة فقط) | **لا قسم** |
| و٢ / ٢ — الذَّكاءُ الاصطِناعيُّ | لا نصّ إعراب مهيكل | **لا قسم** |

> هذا يحقّق مطلب «قسم مستقلّ في كل درس يحتوي إعرابًا» بلا اختراع حرف واحد.

### ٤.٢ قيود غير قابلة للتفاوض في التنفيذ

- **لا يتغيّر** أي نصّ في `src/data/**` · لا تغيير في الأسئلة/الخيارات/المفاتيح/الترتيب/شروط الاختبارات.
- **لا يتغيّر** `learningProgress.ts` ولا `draftStorage.ts`، ولا مفاتيح التخزين.
- **بروتوكول كل درس يبقى كما هو**: تسميات أزرار «تحقّق من إجاباتي» / «تحقق من إجابتي» / «تحقّق» تختلف بين الدروس لأن اختباراتها تلتقطها حرفيًا — سأوحّد **الإطار البصري** لا المنطق ولا النصوص.
- كل كلاس تلتقطه الاختبارات يبقى (`.lesson-step-position`, `.l1-activity`, `.source-badge`, `.u2l3-poem*`, …).

### ٤.٣ ما سيُحذف (بعد تأكيد عدم الاعتماد)

| العنصر | بديله | شرط الحذف |
|---|---|---|
| صفحة `Lesson1IrabPage` كطبقة Overlay | قسم الإعراب داخل الدرس (أو صفحة كاملة إن اخترت إبقاءها) | بعد اختبار الدورة درس → إعراب → درس |
| `Lesson1Explanations.IrabSection` (المدفونة في القواعد) | `ParsingSection` | بعد التحقق من عدم فقدان أي سجلّ |
| البلوكات المنسوخة داخل المصيّرات الستة | مكوّنات المحتوى | بعد ترحيل كل درس ونجاح اختباراته |

## ٦) سؤالان للاعتماد

1. **قسم الإعراب مقابل صفحة الإعراب الكاملة**: أُدمج الـ١٩ جملة داخل قسم الإعراب في الدرس وأحذف الـOverlay (أنصح بهذا: التنقّل يصبح طبيعيًا والموضع لا يضيع)، أم أبقي «صفحة الإعراب الكاملة» بجانب القسم؟
2. **ترتيب الترحيل**: أبدأ بالدرس ٢ (الأصغر وتغطيته كاملة) ثم بقية الدروس، أم تفضّل البدء بالدرس ١ لأنه الأكثر استخدامًا؟
