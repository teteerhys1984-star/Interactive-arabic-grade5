## 2. سبب المشكلة الفعلي

لم يكن السبب حجم خط ولا مسافة ناقصة، بل **تعارض في إسناد خلايا الشبكة (CSS Grid)**:

```
.lesson-nav-button { grid-template-columns: 2rem minmax(0, 1fr) auto; }   /* 3 مسارات */
.lesson-step-current-marker { grid-column: 3; grid-row: 1; }              /* النقطة  */
.lesson-nav-item.is-current .lesson-step-status { grid-column: 3; grid-row: 1; margin-inline-end: .7rem; }
```

كل من التسمية «الآن» والنقطة مُقيَّدان بالخلية نفسها `column 3 / row 1`. المسار من نوع `auto`
يُقاس بعرض أوسع عنصر فيه، وهو هنا عرض التسمية؛ والنقطة بعدها `justify-self: center`،
فوقعت **وسط الخلية** أي فوق الحرفين الأخيرين «آن» في اتجاه RTL (القياس الفعلي:
صندوق النص `1186.45–1206.94`، صندوق النقطة `1187.75–1194.47` → تقاطع كامل `6.72×6.72px`).
`margin-inline-end: .7rem` على التسمية كان يحاول حجز مسافة للنقطة لكنه لا يزيح عنصرًا
آخر داخل الخلية، فلم يمنع التراكب.

## 3. الإصلاح (أقل تغيير ممكن)

منح النقطة مسارًا خاصًا بها في صف الخطوة الحالية فقط:

```css
.lesson-nav-button { grid-template-columns: 2rem minmax(0, 1fr) auto; }        /* كما هو */

.lesson-nav-item.is-current .lesson-nav-button {                                /* الجديد */
  grid-template-columns: 2rem minmax(0, 1fr) auto auto;
  border-inline-start-width: 3px;
}
```

وحُذفت إسنادات `grid-column/grid-row` المتعارضة، مع `margin-inline-end` الزائف، فصار
التوزيع تلقائيًا: [الرقم] [اسم الخطوة] [«الآن»] [النقطة] — ويُعكس تلقائيًا في RTL
لأنه يعتمد على مسارات منطقية لا إزاحات فيزيائية.

**لم يُستخدم** إخفاء المؤشر ولا تقصير النص ولا `text-overflow` ولا إزاحة مطلقة؛
المؤشر والنص والشكل والمسافات كما هي، والنقطة تبعد الآن `7.67px` عن آخر حرف.

لماذا المسار الرابع للصف الحالي وحده: إضافته لكل الصفوف كانت تسحب `7.68px` من عرض
اسم كل خطوة (فاصل شبكة إضافي)، فأدى ذلك إلى التفاف سطر إضافي في العنوان الطويل
«التقويم النهائي للجملة الاسمية» في الدرس الثاني من الوحدة الثانية. بقصر التغيير على
الصف الحالي أصبحت **كل** الصفوف الأخرى متطابقة بكسلًا ببكسل مع ما قبل الإصلاح.

## 5. التحقق

**الأتمتة (كاملة):** `npm test` → **202 اختبارًا في 17 ملفًا، كلها ناجحة** (كانت 198 في 16 قبل الإضافة).
`npm run typecheck` و`npm run build` و`git diff --check` بلا أخطاء.

**الاختبار الجديد يفشل على الشيفرة القديمة** (أُثبت فعليًا بإرجاع ملف الأنماط مؤقتًا):

```
× places the label and the dot in two different grid cells
  → the step button needs a track per child: expected 3 to be greater than or equal to 4
```

**متفحص فعلي في Chromium (خطوط Amiri/Noto Sans Arabic محلية):**

- كل الدروس الستة × كل خطوة (59 خطوة) × عرض 1440 و921: لا تراكب، أدنى فاصل `7.67px`،
  النقطة داخل زر الخطوة دائمًا، التسمية «الآن» مرة واحدة في كل حالة.
- 16 عرضًا من 320 إلى 1920: لا تمرير أفقي مطلقًا (`scrollWidth == clientWidth` في كلها)،
  والشريط يظهر ابتداءً من 921px ويُستبدل بمُنتقي الهاتف عند 920px وأقل كما كان.
- الارتفاعات والالتفاف: مقارنة كل صفوف الخطوات في الدروس الستة قبل/بعد →
  **0 فرق في ارتفاع الصف و0 فرق في عدد أسطر أي عنوان**؛ ارتفاع بطاقة الشريط متطابق.
- الهاتف: لقطة الصفحة قبل/بعد **متطابقة بايتًا ببايت** (لأن شريط الجانب مخفي هناك).
- التفاعل: النقر ينقل `aria-current="step"` والتسمية والنقطة إلى الخطوة المختارة،
  عنوان المحتوى يتغيّر، عرض الزر لا يتغيّر عند التحديد، و`ArrowDown` ينقل التركيز
  إلى زر الخطوة التالية.

## 6. المخاطر والملاحظات المتبقية

1. **حدود الاختبار في jsdom:** لا محرّك تخطيط فيه، لذا يثبّت الاختبار *عقد الإسناد*
   (أربعة مسارات، خليتان مختلفتان، تسمية غير مخفية/مقصوصة) لا الهندسة نفسها.
   الهندسة مُثبتة بقياسات Chromium أعلاه وتبقى عرضة للانحدار عند تغيير الشبكة يدويًا.
2. **خط الصف الحالي:** نال الصف الحالي وحده عرضًا أقل بـ`3.2px` لاسم الخطوة؛ لم يغيّر
   التفاف أي عنوان في الدروس الستة، لكن عنوانًا طويلًا جدًا في المستقبل قد يلتف قبل ذلك.
3. **الخطوط:** قُدّمت المعاينة بخطوط Amiri/Noto Sans Arabic المحلية بدل Google Fonts
   (محجوبة في بيئة العمل)، فقد تختلف تفاصيل التنقيط قليلًا عن الإنتاج — لا يؤثر في القياس
   الشبكي الذي هو موضوع الإصلاح.
4. **لم يُجرَّب** Safari/iOS ولا Firefox ولا قارئات شاشة حقيقية.
5. لقطات المعاينة أُخذت بسكربت محلي غير مُودَع في المستودع (كما في PR #17).
