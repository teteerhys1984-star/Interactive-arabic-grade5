## حالة الإجابات (بعد إصلاح ما بعد PR #24)

- **لا مفتاح إجابة معتمدًا** في المصدر المتاح: التصنيف `approved_key` = ٠، ولا يُنسب أي نصّ إلى الكتاب أو إلى دليل المعلّم.
- **٥٢ نشاطًا `guidance_only`**: إجابة مقترحة أعدّتها المنصة، تُعرض للطالب عبر زر «أظهر الجواب» المشترك تحت عنوان «إرشادات للإجابة» مع تنبيه صريح بأنها ليست معتمدة. مصدرها نصّ النشاط + محتوى الكتاب المعروض (القصيدة، قواعد الرفع/النصب/الجزم، قاعدة الهمزة المتوسطة، فقرة الإملاء، نموذج الرسالة) + أوصاف المنصة للصور.
