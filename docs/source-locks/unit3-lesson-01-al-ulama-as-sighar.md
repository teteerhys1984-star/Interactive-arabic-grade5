# قفل المصدر — الوحدة الثالثة، الدرس الأول: «العُلَماءُ الصِّغار» (ص٧٣–٨٣)

- المصدر الوحيد المعتمد: الصفحات المصوّرة المرفقة (image-1.png = ص٧٣ … image-11.png = ص٨٣) مع القصّات الإضافية (image-12.png … image-27.png) لتأكيد مواضع مطبوعة محددة.
- الهوية: الوحدة الثالثة، الدرس الأول. الرقم «٢» المطبوع أعلى الصفحة الأولى مستبعد بالكامل ولا يُستنتج منه ترقيم.
- العنوان الفرعي المطبوع: «كيف يغدو بنا الحاضر أجمل؟». الشاعر: إبراهيم فهد منصور (كما طُبع دون تشكيل).
- عدد سجلات الأنشطة: ٥٧ (U3L1-73-01 … U3L1-83-02). قاعدة العدّ: كل توجيه محدد يطلب استجابة/إنتاجاً/أداءً مستقلاً = سجل واحد؛ التوجيهات التمهيدية بلا أداء مستقل = كتل تعليمات.
- لا يوجد مفتاح إجابة معتمد في المصدر: لا اختبار درس، لا دليل معلم، لا حلول، لا تصحيح تلقائي، لا درجات. الأنشطة تدريب بمسودات فقط.
- الاستماع (ص٧٣): الأسئلة الثلاثة U3L1-73-05/06/07 معروضة كما طُبعت بلا حلول، مع تنبيه «التسجيل غير متوفر». لا يُخترع تسجيل ولا نصّ استماع. قصيدة ص٧٤ نصّ قراءة فقط ولا تُنسب إلى نصّ الاستماع (العلاقة غير مثبتة).
- التاريخ المطبوع في نموذج الرسالة «٢٠١٨/٢/٢٦» يُعرض كما طُبع دون تغيير.
- نماذج الخطّ بخطّ الرقعة (ص٨٠–٨١) لا تُحاكى بخطّ الحاسوب؛ تُنفَّذ يدوياً على ورقة مسطّرة.
- صور ص٧٣ وص٨٣ لا تُعاد إنتاجها؛ تُعرض ملاحظة منصة محايدة مختصرة لما يظهر فيها دون استنتاج معنى، ولا تُنسب إلى الكتاب.
- الخطوة ١١ خلاصة مستقلة موسومة «شرح المنصة»، ليست نصّاً من الكتاب.
- الفجوات المعلنة (G-01، G-03، G-09، G-10، G-11، G-12) تبقى معلنة؛ لا تُملأ بتخمين.
