# Interactive Arabic Grade 5 — اللغة العربية التفاعلية (الصف الخامس)

منصة تعليمية تفاعلية حديثة لمنهاج مادة اللغة العربية للصف الخامس الأساسي.

---

## 📌 المرحلة الحالية: التأسيس الهيكلي والتقني (Foundation Phase)

وفقاً للقواعد والضوابط الصارمة لنزاهة المحتوى التعليمي، **لم يتم إدراج أو اختراع أي وحدات أو دروس أو تدريبات أو أسئلة امتحانية من الكتاب المدرسي**، لأن الكتاب المدرسي الرسمي لم يتم تزويده بعد.

تم بناء وتثبيت البنية التحتية المتكاملة الآتية:
1. **دعم كامل للغة العربية والاتجاه (RTL)** وتأمين عزل ثنائي الاتجاه (BiDi Isolation) للأرقام والنصوص اللاتينية والمصطلحات.
2. **سجل منهاج موجّه بالبيانات (Data-Driven Curriculum Registry)** ينطلق بحالة خلو تامة (`units: []`).
3. **قاعدة اكتمال الوحدة الصريحة (Explicit Unit Completion Rule)**: لا يُعتبر أي درس نهائياً ولا يُتاح اختبار الوحدة الشامل (50–60 سؤالاً) إلا بإعلان صريح ومعتمد من المالك: *"This is the last lesson in the unit"*.
4. **عقد اختبارات الدروس والوحدات (Assessment UX Contract)**:
   - اختبار الدرس: 20 سؤالاً بالتمام والكمال.
   - اختبار الوحدة: 50–60 سؤالاً للوحدة المكتملة رسمياً فقط.
   - أثناء الاختبار: حجب النتيجة الفورية وخيارات الصواب والخطأ تماماً.
   - بعد الإرسال: عرض فوري للدرجة، النسبة، عدد الإجابات الصحيحة والخاطئة، ومراجعة تعليمية معللة.
5. **نظام تتبع المصادر ومقروئية الكتاب (Source Readability & Traceability)** لربط كل درس وسؤال برقم الصفحة الموثقة ونوع المادة.
6. **بوابة المعلم والإشراف التربوي والمدقق الآلي للنزاهة (Audit Engine)** لاكتشاف أي تكرار أو نقص في الأسئلة أو غياب لمصادر الكتاب.
7. **نشر تلقائي على صفحات غيت هاب (GitHub Pages)** بمسار أساسي: `/Interactive-arabic-grade5/`.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **React 18** (Functional Components + Strict Mode)
- **TypeScript** (Strict Type Checking)
- **Vite 6** (Fast Build & Static Bundle Optimization)
- **CSS3 Design System** (محطة ألوان هادئة وتربوية: الزمردي العربي الحبري والرمال الذهبية)
- **Vitest & React Testing Library** (اختبارات التحقق من العقود والقواعد)
- **GitHub Actions** (سير عمل النشر المؤتمت لـ GitHub Pages)

## 🚀 التشغيل المحلي (Local Development)

```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev

# الفحص النوعي (Typecheck)
npm run typecheck

# تشغيل اختبارات الجودة والنزاهة
npm test

# البناء للإنتاج
npm run build
```

## 📋 مسار العمل القادم فور استلام صفحات الكتاب المدرسي (Source-Readability Workflow)

```text
استلام صور صفحات الكتاب
         ↓
فحص المقروئية (Source Readability Report)
         ↓
تأكيد وضوح النصوص والتأكد من عدم وجود قص أو تشويش
         ↓
استخراج هيكل الوحدات والدروس وتوثيق أرقام الصفحات
         ↓
تسجيل الوحدات في curriculumRegistry
         ↓
تصميم الأنشطة التفاعلية والخطوات التعليمية (LessonFlow)
         ↓
بناء بنك الأسئلة (20 سؤالاً لكل درس / 50-60 للوحدة المكتملة)
         ↓
تدقيق النزاهة واكتمال مفاتيح الإجابات عبر Audit Engine
```
