# Interactive Arabic Grade 5 — اللغة العربية التفاعلية (الصف الخامس)

منصة تعليمية تفاعلية لمنهاج مادة اللغة العربية للصف الخامس الأساسي، مبنية على **React + TypeScript + Vite**، ومُنشورة على **GitHub Pages**.

> **منهجية هذا الملف:** كل رقم أو اسم أو حالة أدناه مأخوذ من ملفات المستودع نفسها (سجل المنهاج، ملفات البيانات، الاختبارات، أقفال المصادر، وتقارير التغطية). عند أي تعارض مع أي وثيقة أقدم، **ملفات الكود والتقارير هي المرجع**. عند أي تعارض مع هذا الملخص، **الكود هو المرجع**.
> **حالة المراجعة:** 2026-11-14 — على أساس `main` @ `2b28baa` (دمج PR #18).

---

## 1) تعريف المشروع وحالته الحالية

ما نُفِّذ فعلًا:

- وحدتان مسجَّلتان في سجل المنهاج (`src/data/curriculumRegistry.ts`) تغطيان **الصفحات 4–68** من الكتاب المدرسي: الوحدة الأولى (مكتملة) والوحدة الثانية (غير مكتملة).
- **6 اختبارات** مسجَّلة فعليًا: خمسة اختبارات دروس (20 سؤالًا لكل منها) واختبار وحدة واحدة (50 سؤالًا للوحدة الأولى).
- **مراجعة وحدة واحدة** «تقويم الوحدة الأولى» (صفحات 36–38) بواجهة طالب وحلول معلم، مسجَّلة كعنوان مستقل لا كدرس.
- **5 دلائل معلم** (دروس الوحدة الأولى الثلاثة + درسّا الوحدة الثانية الأول والثاني)، يُثبت اختبارات آلية تطابق أنشطتها مع أقفال المصدر وسجلات التغطية.
- أقفال مصدرية لستة عناصر درسية + 5 تقارير تغطية + 3 تدقيقات مصدرية داخل `docs/`.

ما **لا** يُدَّعى:

- المنهاج كاملًا لم يُغطَّ: المسجَّل هو ما ورد في الصفحات 4–68 فقط، ولا محتوى مسجَّل لصفحات أو وحدات خارج ذلك.
- الوحدة الثانية **غير مكتملة** بقرار مقصود (قاعدة الاكتمال أدناه)، وليس لها اختبار وحدة.
- المحتوى لا يُستكمل بالاستنتاج: أي نص أو إجابة غير مقروء أو غير موثّق يُعلَن كحدّ معلَّم ولا يُخترع.

## 3) البنية التقنية

- **React 18** (مكوّنات وظيفية + Strict Mode)، **TypeScript ~5.6** (فحص صارم)، **Vite 6** (بناء ثابت)، **Vitest 2 + React Testing Library + jsdom**.
- **البيانات قبل العرض**: لا يُكتب أي محتوى مُثبَت (hardcoded) داخل المكوّنات.
  - `src/types/curriculum.ts` — أنواع الوحدات والدروس ومراجع المصدر وأنواع الأسئلة وعقد واجهة الاختبار.
  - `src/data/curriculumRegistry.ts` — الوحدات والدروس واكتمال الوحدات ومراجع الصفحات والوصول إلى مراجعة الوحدة.
  - `src/data/assessments.ts` — السجل المركزي للاختبارات الستة.
  - `src/data/<درس>/` — لكل درس: `content.ts` (الخطوات والكتل)، `activities.ts`، `lessonTest.ts` (إن وجد)، `teacherGuide.ts` (إن وجد)، `sourceMeta.ts`، `sourceAudit.ts` (إن وجد).
- **مسار العرض** (تنقّل داخلي في `src/App.tsx` بلا مكتبة راوتر): `home` → `HomePage` · `unit` → `UnitPage` · `lesson` → `LessonFlow` = `LessonShell` (الرأس + شريط الخطوات + التنقّل) ثم `StepRenderer` مع مصيّر خاص بكل درس (`Lesson1StepRenderer` … `Unit2Lesson3StepRenderer`) · `unit_review` → `Unit1ReviewFlow` · `lesson_test`/`unit_test` → `AssessmentShell` (`QuestionRenderer` + `TestSolutions`) · `teacher`/`solutions` → `TeacherAreaShell` و`Unit1ReviewSolutions`.
- **الاتجاه واللغة**: `index.html` بـ`dir="rtl"`، وعزل ثنائي الاتجاه (BiDi) للأرقام واللاتينية عبر `src/components/common/BiDi.tsx` و`src/utils/arabicDigits.ts`.
- **الجلسة والمسودات**: `src/utils/learningProgress.ts` (استئناف موضع الدرس داخل الجلسة فقط، بلا نسبة إكمال مُختلقة)، `src/utils/draftStorage.ts` (مسودات إجابة)، `src/utils/testEvaluator.ts` و`src/utils/audit.ts` (تقييم وتدقيق آلي).

## 4) الاختبارات والجودة

### الأوامر (مطابقة لـ `package.json`)

```bash
npm ci              # تثبيت الحزم كما تحددها package-lock.json
npm run dev         # خادم التطوير (vite)
npm test            # vitest run — اختبارات الجودة والنزاهة

npm run typecheck   # tsc -b — الفحص النوعي
npm run build       # tsc -b && vite build — بناء الإنتاج
```

### ما تغطيه الاختبارات فعلًا

- **عقود سجل المنهاج** (`foundation.test.tsx`): وجود وحدتين، أسماء وأعداد الدروس، توفّر اختبار الوحدة للوحدة المكتملة فقط.
- **محاذاة المصدر مع التنفيذ** (أرقام مثبتة بالاختبارات): الدرس الأول — **84 سجل قفل** تُعرض نصًّا + **39 نشاطًا منفَّذًا بـ39 حلًّا**؛ الدرس الثاني **53 = 53 = 53**؛ الدرس الثالث **51 = 51 = 51**؛ تقويم الوحدة **10 سجلات ↔ 32 عنصر طالب ↔ 32 حل معلم**؛ درسا الوحدة الثانية **45 = 45 = 45** و**51 = 51 = 51**؛ ودرسها الثالث **43 نشاطًا** (بلا دليل معلم، معلنًا). مع حالات `passed` لدوال التدقيق: `auditLesson2Coverage` · `auditLesson3Coverage` · `auditUnit1ReviewCoverage` · `auditU2L1Coverage` · `auditU2L2Coverage`، إضافة إلى `auditCurriculum` العام في اختبارات الأساس.
- **عقد واجهة الاختبار** (`unit1.test.tsx` وغيرها): حجب الدرجة وإجابات الصواب/الخطأ أثناء المحاولة، ثم عرض الدرجة والنسبة والصحيحة والخاطئة والمراجعة المعلَّلة بعد الإرسال، ومنع إعادة التقييم الفوري.
- **مراجعة الوحدة** (`unit1Review.test.tsx`): الأعداد 7/23/10/32، وتوفّر مراجعة الوحدة واختبار الوحدة في مكانهما الصحيح.
- **استئناف الجلسة** (`learningSession.test.tsx`): عودة إلى موضع الخطوة، ومسودات كمحاولة غير مُسلَّمة لا كنتيجة.
- **إتاحة الوصول وشريط الخطوات** (`lesson2-platform-a11y.test.tsx`، `lessonStepIndicator.test.tsx`): عقود PR #17 وPR #18 الموثقة في `docs/redesign/`.
- **سلامة المحتوى**: تفرد معرّفات الأسئلة والأنشطة، وعدم عرض مفاتيح إجابة للعناصر التي لا مفتاح لها.

التحقق الآلي لا يغطي المطابقة القرائية نفسها: المطابقة مع الكتاب موثّقة في أقفال المصادر وتقارير التغطية (القسم التالي)، والاختبارات تثبت أن هذه الوثائق مطبَّقة في البيانات والعرض.

## 5) المصادر والنزاهة التعليمية

- **أقفال المصدر** `docs/source-locks/` (6 ملفات): لكل درس مسجَّل قفل ينسخ ما ورد في الصفحات كما هو، ويرتبط بالمرفقات المعتمدة حصريًا (صور الصفحات وقصّات التكبير المرسلة من المالك)، **بلا اعتماد أي نص من الشبكة أو من دروس سابقة أو من ملف خارجي — إلا ما يعتمده المالك صراحةً كمرجع علمي مساند وفق النطاق الموثّق في «قواعد النزاهة» أدناه**.
  - `lesson-01-al-smaka-al-dhahabia.md` (4–11) · `lesson-02-bil-rayi-wal-rayi-al-akhar.md` (12–24) · `lesson-03-lughati.md` (25–35) · `unit2-lesson-01-mukhtari-min-biladi.md` (40–49) · `unit2-lesson-02-aldhaka-al-istinaai.md` (50–60) · `unit2-lesson-03-bil-ilmi-tarqa.md` (61–68).
- **تقارير التغطية** `docs/coverage/` (5 تقارير): تربط كل سجل مطبوع بعنصر في منطقة الطالب وحل في منطقة المعلم — تقرير واحد لدروس الوحدة الأولى الثلاثة، وتقرير لتقويمها، وتقرير لكل درس من دروس الوحدة الثانية الثلاثة.
- **التدقيقات المصدرية** `docs/source-audits/` (3 ملفات): تقويم الوحدة الأولى (36–38)، وجدول مواضعه المفتوحة، وتدقيق الدرس الثاني من الوحدة الثانية (50–60).
- **قواعد النزاهة المطبَّقة في البيانات والاختبارات:**
  1. **لا اختراع**: أي نص أو إجابة أو مفتاح غير مقروء من المصدر لا يُكتب، ويُعلَن كحدّ (`uncertaintyNote` في مرجع المصدر) لا يُعدّ «موثقًا».
  2. **الغياب يُعلن لا يُملأ**: تسجيلات الاستماع غير المتوفرة تُصرَّح بغيابها ويُعتمد النص المطبوع مدخلًا للمهمة.
  3. **تمييز بين محتوى الكتاب والمراجع العلمية:**
     - **محتوى الكتاب المدرسي**: المرجع الحاكم لنصوص الدروس وأسئلتها وإجاباتها وأنشطتها هو مرفقات الكتاب الرسمية المعتمدة وأقفال المصادر؛ **لا يجوز اختراع نص أو سؤال أو إجابة أو نشاط مدرسي غير موثّق فيها**.
     - **المراجع العلمية الخارجية**: لا تُعتمد إلا **بموافقة صريحة من مالك المشروع**، لإسناد **شرح علمي محدد** فقط، مع توثيق نطاق استخدامها في وثيقة القرار؛ لا تحل محل الكتاب ولا تمنح إذنًا بإضافة محتوى مدرسي غير موجود فيه، ولا يُعمَّم هذا الإذن على درس أو وحدة أخرى، وليس استخدامها مسموحًا تلقائيًا.
     - **مثال موثق ومحصور**: مرجعا جامعة الملك سعود («أبنية المصادر القياسية» و«الهمزة في أول الكلمة») اعتمدهما المالك لإسناد شرح **المصدر** و**همزة القطع** في **الوحدة الأولى، الدرس الثاني «بالرأي والرأي الآخر»، الخطوتين `l2-s5` و`l2-s6` فقط** — نطاق الاستخدام موثّق في `docs/redesign/pr-02-source-authorization.md` ويحدّده `docs/redesign/pr-02-lesson2-grammar-spelling-spec.md`.
  4. **المحاذاة تُثبت آليًا**: دوال تدقيق داخل `src/data/*/sourceAudit.ts` يغطيها اختبارات `src/test/`.
  5. **بوابة حلول الاختبارات أمامية فقط**: موقع ثابت على Pages، وكل من يقرأ حزمة JS يرى المفاتيح؛ البوابة تبعد التصفح العابر وليست حاجزًا أمنيًا (محدودية موثقة صراحةً في `src/App.tsx`).
- **وثائق عملية حديثة**: تقارير PR الأخيرة في `docs/redesign/` — `pr-17-a11y-preview-report.md` (إتاحة تدريبات الدرس الثاني) و`pr-18-step-indicator-report.md` (إصلاح مؤشر «الآن» في شريط الخطوات) — مع لقطات المعاينة في `docs/redesign/preview/`.

## 6) الفجوات والقيود المعروفة

كل ما يلي **معلن في وثائق المشروع الحالية**، ولا يُقدَّم أيٌّ منها على أنه محتوى مكتمل:

1. **الوحدة الثانية غير مكتملة** (`isComplete: false`، بلا `unitTestId`): قاعدة مقصودة — لا يُعرض اختبار وحدة إلا بعد إعلان صريح من المالك.
2. **الوحدة الثانية بلا موضوع مسجَّل**: صفحة الفاصل لم تكن ضمن الصور المزوَّدة (`src/data/curriculumRegistry.ts`).
3. **درس «بِالْعِلْمِ تَرْقَى» بلا اختبار درس وبلا دليل معلم**: لا مفتاح إجابة معتمد في المصدر، فلا يُخترع مفتاح (`src/data/curriculumRegistry.ts`، `docs/coverage/unit2-lesson-03-coverage.md`).
4. **تسجيلات الاستماع غير متوفرة** في المرفقات لصفحات: 12 و25 (الوحدة الأولى)، و40 و50 و61 و66 (الوحدة الثانية) — يُعلَن الغياب ويُعتمد النص المطبوع (أقفال المصدر وسجلات `sourceMeta`).
5. **رسوم الخط والأشكال وبطاقات اللعب** (مثل صور الخط ص47 و58، والبطاقات ص68): لا تُستبدل بمحتوى من خارج المصدر (`docs/coverage/unit2-lesson-03-coverage.md`، `docs/source-locks/unit2-lesson-02-aldhaka-al-istinaai.md`).
6. **تقويم الوحدة الأولى**: 5 مواضع قراءة مفتوحة لا تمس أي إجابة (`LIM-01`، `LIM-02`، `LIM-03`، `LIM-06`، `LIM-08`)، و3 مواضع حُسمت ببيّنة المالك (`docs/source-audits/unit-1-review-open-limit-items.md`).
7. **الدرس الأول «السَّمَكَةُ الذَّهَبِيَّةُ»**: بندان مطبوعان بلا مفتاح بقرار موثّق (`L1-036`، `L1-080`)، وتنبيه قرائي لصفحة 11، وتصحيح/قراءات معتمدة مسجَّلة (`docs/coverage/unit-1-coverage-report.md`).
8. **الدرسان الثاني والثالث في الوحدة الأولى**: فجوات مصدر معلنة في قفلَيهما (استماع، نص قصيدة كامل، نماذج خط، نص حوار، مواضع تشكيل) — مفصَّلة في `docs/source-locks/lesson-02-bil-rayi-wal-rayi-al-akhar.md` و`docs/source-locks/lesson-03-lughati.md` و`docs/coverage/unit-1-coverage-report.md`.
9. **لا محتوى مسجَّل خارج الصفحات 4–68**: صفحات الغلاف وما قبلها، وما بعد ص68، والوحدات اللاحقة — لم يُسجَّل منها شيء، ولا يُستنتج وجوده.
